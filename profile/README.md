### ⚙️ Wie wir Software entwickeln

Wir setzen nicht auf den aktuellen Hype, ein Sprachmodell auf Probleme zu werfen, die man mit sauberem Code zuverlässiger löst:

1. **Deterministische Logik vor KI**: DNS-Einträge, WHOIS-Alter, SSL-Zertifikate und Registerdaten sind binär. Unser Code prüft sie in Millisekunden exakt. KI nutzen wir gezielt dort, wo es um unstrukturierte menschliche Sprache und semantische Zusammenhänge geht.
2. **Handwerk & Standards**: Modernes PHP 8 mit strikter Typisierung (`declare(strict_types=1);`), Symfony-Framework, PSR-Standards und Server-Side Rendering (SSR) ohne überladene JavaScript-Megabytes.
3. **Kompromisslose Tests**: 100 % automatisierte Testabdeckung mit PHPUnit, PHPStan auf striktester Stufe und PHP-CS-Fixer in CI/CD.
4. **Datenschutz by Design**: Serverstandort Deutschland, KI-Inferenz in der EU, keine Werbe-Tracker, kein KI-Training mit Kundendaten.
